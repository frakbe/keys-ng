# Keys NG M1.17 — Security consolidation

Version: `0.1.17.dev0`

M1.17 intentionally prioritizes security reviewability and hardening over new end-user features.

## Security changes

- Ordinary record reads now verify the record against the signed catalog: filename UUID, payload UUID, ciphertext SHA-256 and revision must agree.
- Isolated rollback/replacement of a record therefore fails closed. Coordinated rollback of both record and catalog remains a documented residual risk.
- POSIX vault root, `records/` and `inbox/` are explicitly `0700`; vault/config ciphertext files remain restrictive.
- Signature-required vault policy now requires a configured signer and trusted signer list.
- GnuPG process key selection now accepts only complete 40/64-hex OpenPGP fingerprints.
- Added atomic-write fault injection and deterministic malformed-input parser stress tests.
- Added a dependency-free AST security check for forbidden shell/dynamic-code APIs.

## Reviewer documentation

English and Italian now each contain:

- `CODE_REVIEW_MANUAL.md` — exhaustive source-derived reference for every Python class/function, including nested helpers;
- `THREAT_MODEL.md`;
- `VAULT_FORMAT_1.0.md`;
- `SECURITY_REVIEW.md`;
- `MEMORY_REVIEW.md`;
- `RELEASE_SECURITY_CHECKLIST.md`.

The code-review manual is generated by `tools/generate_code_review_manual.py`. A regression test independently walks the AST and fails if either language manual lacks any Python class/function marker.
